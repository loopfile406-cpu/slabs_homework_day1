An Operating System (OS) is the most important software on a computer because it acts as a manager. It controls the computer's memory, processes, and all of its hardware and software.

The primary responsibilities of an Operating System include:
 -Managing Hardware: It controls devices like the keyboard, mouse, monitor, and printer.
 -Running Sofware:It loads and runs programs (like web browsers or games) and makes sure they do not crash each other.
 -Managing Files:It organizes where files are saved, deleted, or moved on your storage drives.
 -Providing user interface:It creates the visual screen, buttons, and menus you use to interact with the computer.

Hardware vs. Software Instructions:
The fundamental difference between hardware and software comes down to physical presence versus digital commands
 -Hardware: The physical, tangible components you can touch. for exaple wires 
 -Software:The intangible, digital instructions and code that tell hardware what to do

5 Internal Hardware Components:
 -CPU:The "brain" that processes data and executes instructions
 -Motherboard:The main circuit board that connects all components together
 -RAM:Super-fast, temporary memory used for active tasks
 -SSD:Permanent storage for files, programs, and the OS
 -PSU:Converts wall electricity into usable power for the computer

RAM VS SSD
RAM:Temporary, ultra-fast memory that completely erases the instant power is turned off
SSD:Permanent, long-term storage that safely retains your data even without power
